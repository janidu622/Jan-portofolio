# Janidu Siriwardhana — Portfolio

A Next.js and TypeScript portfolio with an interactive Three.js astronaut scene and day/night theme.

## Run locally

Install Node.js and run `npm install` followed by `npm run dev`. Open http://localhost:3000.

## Update the portfolio

- Edit `data/projects.ts` to add, remove or update project cards, links, tags and status.
- Edit `app/page.tsx` to change the biography, contact details, education and profile links.
- Replace the GitHub avatar URL in `app/page.tsx` with your own photo URL when ready.
- Update colors and layout in `app/globals.css` and the 3D scene in `components/Scene.tsx`.

The displayed project artwork is illustrative. CODTrace is an interactive frontend prototype. Coding profile links lead to their respective services.
